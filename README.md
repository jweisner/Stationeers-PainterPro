# PainterPro

A Stationeers mod that paints a whole pipe, cable, chute or robotic arm rail
network in one go.

## Controls

With a spray can or spray gun in hand:

| Input | Effect |
|---|---|
| Paint | Paints only the item you spray (vanilla behaviour) |
| Shift + paint | Paints the entire connected network |
| Ctrl + paint | Paints a checkered pattern across the network |

Checkered paint alternates by counting pieces outward from the one you
spray, so a long pipe or cable counts as a single piece and junctions take
their turn in the pattern.

On a pipe network only the pipe pieces are painted. Devices on the run
(in-line tanks, vents, drains, connectors) are left alone, so a checkered
gas-mix marking never lands half on a tank. Spraying a planter or a passive
vent paints the other planters or vents on that network instead.

Works in singleplayer, on a listen server and on a dedicated server. The mod
must be installed on the server and on every client.

## Install

Requires [StationeersLaunchPad](https://github.com/StationeersLaunchPad/StationeersLaunchPad).

Subscribe on the
[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3840045914),
or install by hand: unzip a release into your Stationeers `mods/` directory so
you end up with `mods/PainterPro/PainterPro.dll` and `mods/PainterPro/About/`.

If you have NetworkPainter installed, remove it first. Both mods react to the
same spray, and running them together paints each network twice with
conflicting checkered patterns.

## Building

Set your game path in `Stationeers.User.props`, then:

```
dotnet build PainterPro
```

To copy the build straight into your local mods directory, create a
`Deploy.User.props` beside it that sets `StationeersSaveDataDirectory`.

The Workshop thumbnail and in-game preview are generated by
`art/make_art.py`; its docstring has the commands to render them.
